# Lead Management System (Mini CRM)

##  Tech Stack

* Frontend: React
* Backend: Node.js + Express
* Database: PostgreSQL

##  Features

* Add Lead
* View Leads
* Update Status (Interested / Not Interested / Converted)
* Delete Lead
* Form Validation

##  How to Run

### Backend

cd backend
npm install
npm run dev

### Frontend

cd frontend
npm install
npm start

##  API Endpoints

* GET /leads
* POST /leads
* PUT /leads/:id
* DELETE /leads/:id

##  Database

Table: leads
Columns: id, name, phone, source, status
